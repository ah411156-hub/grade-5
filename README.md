# Our Town, Our Friends! 🌈

A colorful, animated, self-contained English lesson for Grade 5 students. It introduces public places, inviting friends, polite acceptance and refusal, swimming pool rules with **must** and **mustn’t**, and a friendly email using **also** and **too**.

## Run it

Open `index.html` in any modern web browser. No build tools, dependencies, or internet connection are required. Use **Play** for the animated scene-by-scene presentation, or use **Back** and **Next** to explore at your own pace. Keyboard users can move between scenes with the left and right arrow keys.

The lesson includes captions, engaging character dialogues, responsive layouts, and reduced-motion support.
